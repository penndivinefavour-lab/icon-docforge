# SUPPORT — ICON DocForge

## Getting Help

### Quick Start

1. **Check the README** - Most common questions are answered there
2. **Run diagnostics** - Use the built-in diagnostics tool: Settings → Diagnostics
3. **Check supported formats** - See the capability matrix in README

### Common Issues

#### App Won't Install
- Ensure Android 8.0 (API 26) or higher
- Enable "Install from Unknown Sources" in Settings
- Clear download folder and re-download APK

#### Conversion Fails
- Check file size (max 50MB)
- Ensure file is not corrupted
- Try converting a simpler file first
- Check available storage space

#### App Crashes
- Force stop: Settings → Apps → ICON DocForge → Force Stop
- Clear cache: Settings → Apps → ICON DocForge → Storage → Clear Cache
- Reinstall the APK

#### File Won't Open After Conversion
- Grant storage permission: Settings → Apps → ICON DocForge → Permissions → Storage
- Use a different file manager
- Check if the output format is supported by your viewer

### Unsupported Conversions

If a conversion shows as unavailable:
- Check the [Capability Matrix](README.md#supported-formats)
- Some converters require additional packages
- These are noted clearly in the app interface

## FAQ

### Q: Is my data safe?
**A:** Yes. All processing happens locally. No documents are ever uploaded or transmitted.

### Q: Do I need an account?
**A:** No. There is no registration, login, or account system.

### Q: Does it work offline?
**A:** Yes. Once installed, the app works completely offline.

### Q: Can I use it for commercial purposes?
**A:** Yes. The app is MIT licensed—use it freely for personal or commercial projects.

### Q: Will future versions cost money?
**A:** No. ICON DocForge will always be free and open source.

### Q: Why does some functionality say "unavailable"?
**A:** Those features require additional Python packages not included in the base APK. You can install them manually in Termux if desired.

### Q: How do I report a bug?
**A:** Create an issue on GitHub: https://github.com/penndivinefavour-lab/icon-docforge/issues

### Q: Can I request a feature?
**A:** Absolutely! Submit a feature request on GitHub with the "enhancement" label.
