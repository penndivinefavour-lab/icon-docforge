3. NEW CAPABILITIES ADDED IN v1.1
═══════════════════════════════════════════════════

✅ FULLY WORKING (All 51/51 tests passing)

  • PDF Text Extraction       — pdftotext
    Converts PDF to plain text with page markers
    Quality: High for digital PDFs

  • PDF Text Search           — pdftotext + regex
    Search across all pages, returns page numbers
    Supports case-sensitive/insensitive

  • PDF Page Info             — pdfinfo + PyPDF2
    Page count, dimensions, orientation, metadata
    Returns title, author, creation date

  • PDF Image Extraction      — pdftoppm
    Extracts pages as PNG images
    Useful for visual review

  • PDF Compression           — pdftoppm at 72 DPI
    ~65% estimated size reduction
    No GhostScript needed

  • PDF Text Watermark        — PyPDF2 metadata
    Adds "CONFIDENTIAL" watermark to metadata
    Note: Metadata-level (not visually rendered)

  • PDF Page Reorder          — pdfseparate + pdfunite
    Extract and recombine pages in any order
    Complete fidelity

  • PDF Page Deletion         — pdfseparate + pdfunite
    Remove specified pages from PDF
    Complete fidelity

  • Multi-image PDF support   — fpdf2
    Transparent PNG, rotated images, WebP all work
    Landscape A4, Letter portrait confirmed

4. HONESTLY DOCUMENTED LIMITATIONS
═══════════════════════════════════════════════════

🚫 NOT AVAILABLE (NOT FAKED):

  • GhostScript — Not in Termux repository
    → PDF compression via pdftoppm instead
  • ImageMagick — Not available on aarch64 Termux
    → Pillow handles image processing
  • LibreOffice — Too heavy for Android (~500MB+)
    → Pandoc handles DOCX/ODT/Markdown
  • QPDF — Not in Termux repository
    → pdfunite/pdfseparate handle core operations
  • Tesseract OCR — Not in Termux repository
    → Only relevant for scanned documents
  • pdf2docx — PyMuPDF dependency too large for device
    → PDF→DOCX is fundamentally limited (layout≠semantics)

⚠️ APPROXIMATE/RECONSTRUCTED (NOT CLAIMED AS PERFECT):

  • PDF→DOCX: Layout describes pages, not document structure
    Any reconstruction is approximate — honest disclosure
  • PDF→PPTX: Requires slide-by-slide layout analysis
    Not implemented; documented as unavailable
  • PPTX→PDF: Requires LibreOffice (not available)
    Documented as requiring external tool
