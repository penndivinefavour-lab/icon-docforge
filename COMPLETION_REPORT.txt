## Key Technical Decisions

### Android APK Approach
- **Capacitor 6.x** with proven pattern from ICON QuickTools
- **Package ID**: `com.iconstudios.docforge`
- **Version**: 1.0.0
- **Min SDK**: 23, **Target SDK**: 34
- **Local HTTP server** on port 8080 bridges web UI and Python engine
- **Important limitation**: Python binaries may not be available in the APK context — documented in ANDROID.md

### CI/CD Approach
- **Reused proven workflow patterns** from ICON QuickTools
- **GitHub Actions** for automated testing, building, and releasing
- **Tag-triggered builds**: `android-v*` tags trigger APK builds
- **Release artifacts**: APK upload + SHA-256 checksums + GitHub Release creation

### No Sensitive Data
- No signing keys, keystores, credentials, tokens, API keys, or private certificates committed
- All sensitive configuration uses GitHub Actions secrets
