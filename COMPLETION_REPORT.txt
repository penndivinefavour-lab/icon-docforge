5. CONVERSION MATRIX SUMMARY
═══════════════════════════════════════════════════════════════
SUPPORTED (HIGH-FIDELITY):
  DOCX ↔ PDF (pandoc+weasyprint)
  DOCX ↔ ODT (pandoc)
  DOCX ↔ HTML (pandoc)
  DOCX → TXT/MD/EPUB (pandoc/mammoth)
  PPTX → PDF (pandoc/reportlab)
  XLSX → PDF (openpyxl+reportlab)
  CSV ↔ XLSX (openpyxl)
  Images → PDF (fpdf2)
  PDF → Images (pdftoppm)

SUPPORTED (STRUCTURAL RECONSTRUCTION):
  PDF → DOCX/PPTX/ODT (pdfplumber+python libraries)
  XLSX ↔ ODS (openpyxl+odfpy)
  PPTX → DOCX (outline extraction)
  DOCX → PPTX (semantic transform)
  TXT → DOCX/PDF (pandoc)

EXPERIMENTAL:
  PDF → XLSX (table detection)

UNSUPPORTED:
  ODP → any (no ODP renderer)
  PDF → DOCX (high-fidelity — layout ≠ semantics)
  Macro/encrypted files (security block)

11. KNOW LEGEND LIMITATIONS
═══════════════════════════════════════════════════════════════
Technical Limitations (Termux/Android):
  • No Ghostscript — PDF compression limited to pdftoppm re-render
  • No ImageMagick — Image processing via Pillow only
  • No LibreOffice — Complex formatting approximation
  • No QPDF — PDF manipulation via PyPDF2/pdfplumber
  • No Tesseract OCR — Only digital PDFs supported

Conversion Limitations:
  • PDF→DOCX: Structural reconstruction, not visual fidelity
  • PPTX→PDF: Animations lost (static medium limitation)
  • XLSX→PDF: Charts not rendered, formulas shown as values
  • ODP: No renderer available on Android/Termux
  • Macros: Blocked by security preflight

Performance Notes:
  • Large files (>50MB) may cause memory pressure
  • PPTX→PDF via reportlab is slower than pandoc path
  • PDF→Office reconstruction is CPU-intensive
